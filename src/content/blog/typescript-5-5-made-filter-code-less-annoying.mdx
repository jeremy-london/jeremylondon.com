TypeScript 5.5 made common filter pipelines less noisy through inferred type predicates.

Older versions often needed a helper after mapping optional values:

~~~ts
const scores = studentIds
  .map((id) => scoreByStudent.get(id))
  .filter((score) => score !== undefined)

const average = scores.reduce((sum, score) => sum + score, 0) / scores.length
~~~

A reusable predicate worked:

~~~ts
function isDefined<T>(value: T | undefined): value is T {
  return value !== undefined
}
~~~

The improvement is not permission to write vague filters. Truthiness can remove valid zeroes:

~~~ts
const scores = [0, 82, 91, undefined].filter((score) => !!score)
~~~

Use the condition that expresses the actual boundary:

~~~ts
const scores = [0, 82, 91, undefined].filter(
  (score) => score !== undefined,
)
~~~

The compiler can now carry more of the ordinary case without an assertion:

~~~ts
const visibleItems = items
  .map((item) => item.details)
  .filter((details) => details !== undefined)

return visibleItems.map((details) => (
  <DetailCard key={details.id} details={details} />
))
~~~

Inferred predicates do not excuse side effects or unclear domain logic inside filters. Keep predicates small and truthful.

The feature is modest. Its value is cumulative: fewer helper functions, fewer assertions, and calmer array pipelines.
